ESTRUCTURA DEL PROYECTO
-----------------------
index.html            Pagina principal
vercel.json           Configuracion de Vercel (cabeceras y cache)
.gitignore            Archivos que Git ignora
css/                  tokens, base, components, sections, animations, responsive
js/main.js            Punto de entrada (modulos ES)
js/modules/           Un archivo por funcionalidad
assets/               Favicon e imagenes

ANTES DE EMPEZAR
----------------
- Tener cuenta en https://github.com y en https://vercel.com
  (en Vercel entra con "Continue with GitHub").
- Tener Git instalado (https://git-scm.com).

PROBAR EN LOCAL (opcional)
--------------------------
Los modulos JS necesitan un servidor, no abrir el archivo con doble clic.
En la carpeta del proyecto ejecuta:
    npx serve
o usa la extension "Live Server" de VS Code.

PASO 1: SUBIR A GITHUB
----------------------
El repositorio ya existe y la carpeta ya esta conectada a el
(origin = https://github.com/BebeCarder/avident.git).
Para subir los cambios, dentro de la carpeta del proyecto:

    git add .
    git commit -m "Descripcion del cambio"
    git push

(Si empezaras desde cero en otra carpeta:
    git init
    git add .
    git commit -m "Primera version"
    git branch -M main
    git remote add origin https://github.com/BebeCarder/avident.git
    git push -u origin main )

PASO 2: PUBLICAR EN VERCEL
--------------------------
1. En https://vercel.com/new elige "Import" sobre el repositorio
   BebeCarder/avident.
2. Configuracion:
     Framework Preset ..... Other
     Build Command ........ (dejar vacio)
     Output Directory ..... (dejar vacio)
3. Pulsa "Deploy". En unos segundos tendras una URL como
   https://avident.vercel.app

ACTUALIZAR LA PAGINA
--------------------
Cada "git push" a la rama main se publica solo en Vercel.

IMPORTANTE - CACHE DE CSS/JS/ASSETS
-----------------------------------
vercel.json guarda css/, js/ y assets/ en cache por 1 anio. Si cambias
un archivo de esas carpetas y los visitantes siguen viendo la version
vieja, cambia la version en los enlaces de index.html, por ejemplo:
    <link rel="stylesheet" href="css/components.css?v=2">
    <script type="module" src="js/main.js?v=2"></script>
(Los cambios en index.html se ven de inmediato.)

DOMINIO PROPIO (opcional)
-------------------------
En Vercel: Project > Settings > Domains > Add.

PERSONALIZAR
------------
- Colores, tipografias y espaciados: css/tokens.css
- Textos, direccion y correo: index.html
- Nombre y titulo de la doctora: bloque class="doctor" en index.html
  (seccion Nosotros).
- Pantalla de carga (diente con "Avident" al centro): div id="preloader"
  en index.html y estilos .preloader__* en css/components.css.
- Header: pegado arriba al 100% de ancho, con esquinas inferiores de
  15px (variable --radius-header en css/tokens.css).
- WhatsApp: hay dos botones (hero y seccion Reserva) con href a
    https://wa.me/522213628798?text=...
  El 52 es el codigo de Mexico y 2213628798 el numero de la doctora.
  El mensaje va codificado en la URL (%20 = espacio). Para cambiarlo,
  edita el texto despues de "text=" (puedes codificarlo en
  https://www.urlencoder.org). Tambien esta el enlace tel: en la lista
  de contacto.
- Nota: el formulario de cita es solo visual (muestra una
  confirmacion). Para recibir correos reales se puede conectar a
  un servicio como Formspree o EmailJS.
